## 그 봇보다 더 넣은 것
- 단계별 **수동/자동** 선택 (관리 페이지 설정, 금액 상한) — 자이 요청
- 관리 페이지 (웹) + 관리자 텔레그램 [승인][보류] 버튼
- 받을 주소: 두 번 입력·체크섬 검사·테더 동결 주소 거절·예전 주소와 다르면 경고
- 지급은 오너 지갑에서 직접 → 감시가 출금을 찾아 자동 연결 (서버에 개인키 없음)
- 금액이 끝자리까지 안 맞는 입금·동결 주소 입금 → 관리 페이지 '입금 확인'에서 수동 연결
- 거래방: 당사자 두 명만 가입 승인, 끝나면 링크 폐기·두 사람 내보내기·봇 메시지 삭제 후 다음 거래에 재사용
- 모든 행동 기록 (고치기·지우기 불가)

## 실제로 확인해야 하는 것 (서버·실제 텔레그램에서만)
- 실제 봇 토큰으로 거래방 초대 링크·가입 승인·내보내기 (가짜 텔레그램 테스트로만 확인함)
- 실제 TronGrid 로 소액(예: 1 USDT) 입금·출금 감지
- 관리 페이지 /login 링크·HTTPS
